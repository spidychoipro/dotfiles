# 셸 스크립트 입문 코스

파이썬을 조금 해봤다면, 이 코스는 그 경험을 그대로 이용해 셸(bash/zsh) 스크립트를 배우게 합니다.

## 이 코스의 방식
- 각 과 = **이론(짧게) + 따라하기(example.sh) + 직접 풀어보기(문제)**
- 정답은 각 과의 note.md 맨 아래에 있으니, **먼저 직접 풀어보고** 비교하세요.
- 터미널(zsh)에서 스크립트를 직접 만들어보는 게 제일 빠릅니다.

## 시작 전: 스크립트 실행 방법 (핵심 2가지)
1. 파일 첫 줄에 셔뱅(shebang)을 적는다 → 어떤 해석기로 실행할지 지정
   ```bash
   #!/usr/bin/env bash
   ```
2. 실행 권한을 주고 실행한다
   ```bash
   chmod +x 스크립트.sh
   ./스크립트.sh
   ```
> 파이썬은 `python 파일.py`처럼 해석기를 직접 불렀지만, 셸 스크립트는
> 파일 자체가 실행됩니다 (셔뱅이 해석기를 골라줌).

## 코스 구성
| 과 | 주제 | 파이썬과 비교 |
|----|------|--------------|
| 01 | 셔뱅, 실행 권한, echo | `print()` |
| 02 | 변수, 인자, 입력 | 변수, `sys.argv`, `input()` |
| 03 | 조건문 if | `if / elif / else` |
| 04 | 반복문 for/while | `for`, `while` |
| 05 | 함수 + 실전(파일 정리) | `def`, 실용 예제 |

## 알아두면 좋은 점
- 주석은 `#` (파이썬과 같음)
- 셸은 공백이 중요한 문법이 많습니다 (예: `if [ "$x" = "a" ]` — 대괄호 양옆 공백 필수)
- 터미널에서 자주 쓰는 명령(`ls`, `cd`, `mkdir` 등)을 파일에 적어 실행한다고 보면 됩니다
