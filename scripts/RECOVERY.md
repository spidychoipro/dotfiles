# 복구 가이드 — Plymouth 부팅 애니메이션

이 가이드는 두 가지 목적이 있어요:

1. **플리머스(Plymouth) 부팅 애니메이션 설치** — 안전하게
2. **설치 후 문제가 생겨도 OS로 복귀** — 걱정 없이

> 핵심 원칙: **언제나 "OS에 들어와서 고치는 길"이 남아 있습니다.**
> 플리머스가 아무리 망가져도 안전 복구 엔트리로 부팅하면 평소처럼 OS로 들어옵니다.

---

## 준비물 (한 번만 확인)

- 설치 스크립트 2개가 있는지 확인하세요.

```
ls ~/scripts/
```

`install-plymouth.sh`, `revert-plymouth.sh`, `recovery-menu.sh` 가 보이면 됩니다.

---

## 1단계: 안전장치가 뭔지 한눈에

설치 스크립트는 3겹의 안전장치를 깔아줍니다.

| 안전장치 | 내용 | 없으면 어떻게 되나 |
|---|---|---|
| **A. 백업** | `/efi` 전체 + dracut 설정 + loader.conf → `~/boot-backup/` | 부팅 파티션 복구 불가 |
| **B. 안전 복구 엔트리** | 플리머스 적용 전 initramfs 사본 + 전용 부팅 항목 | 메인 initramfs 손상 시 OS 진입 불가 |
| **C. 타임아웃 보장** | `timeout 0`이면 2초로 변경 | 부팅 메뉴를 열 수 없음 |

가장 중요한 것은 **B** 입니다. 재부팅할 때마다 부팅 메뉴에
`(안전 복구 — 플리머스 없음)` 항목이 하나 더 생깁니다.

---

## 2단계: 설치 (한 번만, 1분 내외)

```
chmod +x ~/scripts/install-plymouth.sh
~/scripts/install-plymouth.sh
```

진행 중:
- sudo 비밀번호를 물어보면 입력하세요.
- `pacman`이 "설치할까요?"라고 물으면 `y` (엔터) 를 누르세요.
- 마지막에 `bootctl list`로 부팅 목록이 뜨는데, **`(안전 복구)` 항목이 보이는지 확인**하세요.

설치가 끝나면 재부팅해서 애니메이션을 확인하세요.

---

## 3단계: 재부팅해서 정상 동작 확인

```
systemctl reboot
```

- 로고가 뜨고 → 로그인 화면 → 바탕화면까지 정상이면 완료!
- 잘 안 보여도 겁내지 마세요. 아래 4단계로 언제든 복구됩니다.

---

## 4단계: 문제가 생기면? (가장 중요)

### 부팅이 멈추거나 검은 화면이 나와요

1. **재부팅**하고, 부팅 화면이 뜰 때 **방향키 ↑ 또는 ↓**를 누르세요.
   (안 눌러도 타임아웃이 2초라 시간이 있지만, 멈추면 메뉴가 유지됩니다)
2. 목록에서 **`EndeavourOS (안전 복구 — 플리머스 없음)`** 항목을 선택하세요.
3. 그냥 평소처럼 부팅되고 OS에 들어옵니다.

> 메뉴가 아예 안 보이면? 재부팅 후 **Esc 키를 연타**하면 부팅 메뉴가 나타납니다.

### 원클릭 복구 메뉴

OS에 들어온 뒤에 이걸 실행하면 전부 처리됩니다.

```
~/scripts/recovery-menu.sh
```

메뉴에서 원하는 걸 고르세요:
1. 상태 확인 (안전 엔트리 / 백업 / 타임아웃)
2. 부팅 안 될 때 대처법 다시 보기
3. **Plymouth 되돌리기** (원상복구)
4. 백업 파일 위치 보기

또는 바탕화면에서 바로: 앱 목록(rofi)에서 **"복구 메뉴"** 를 검색해서 클릭하세요.

### 그래도 부팅이 안 된다면 (최후의 수단)

안전 복구 엔트리마저 안 되면, 설치 스크립트가 만든 **백업**으로 되살립니다.

```
sudo cp -a ~/boot-backup/efi/* /efi/
```

이것도 어렵다면 **EndeavourOS 설치 USB**로 부팅 → "Install" 대신 **Live 환경** 진입
→ 터미널에서:

```
ls /efi/loader/entries/
sudo mkdir -p /mnt/root /mnt/efi
sudo mount /dev/루트파티션 /mnt/root
sudo mount /dev/EFI파티션 /mnt/efi
sudo cp -a /mnt/root/home/*/boot-backup/efi/* /mnt/efi/
```

---

## 되돌리기 (마음에 안 들면 완전 제거)

```
~/scripts/recovery-menu.sh   →   [3. Plymouth 되돌리기]
```

또는 직접:

```
~/scripts/revert-plymouth.sh
```

이 스크립트는:
1. dracut 설정 제거
2. initramfs 재생성 (플리머스 제외)
3. plymouth 패키지 제거
4. 안전 복구 엔트리/이미지/타임아웃 정리

전부 정리됩니다. `~/boot-backup/` 는 문제없을 때까지 남겨두세요.

---

## 파일 위치 정리

| 경로 | 역할 |
|---|---|
| `~/scripts/install-plymouth.sh` | 설치 (6단계 + 안전장치) |
| `~/scripts/revert-plymouth.sh` | 완전 제거 |
| `~/scripts/recovery-menu.sh` | 원클릭 복구 메뉴 |
| `~/boot-backup/` | 부트 파티션 + 설정 백업 |
| `/efi/loader/entries/*-fallback.conf` | 안전 복구 부팅 항목 |
| `/efi/*-fallback.img` | 안전 initramfs 사본 |

## FAQ

**Q. 안전 복구 엔트리로 부팅하면 뭐가 다른가요?**
플리머스 애니메이션만 빠진, 평소와 똑같은 부팅입니다.

**Q. 메인 부팅이 정상인데 안전 엔트리가 자꾸 눈에 거슬려요.**
그냥 두세요. 문제없으면 이 항목은 절대 필요 없지만, 문제 생겼을 때 유일한 출구입니다.

**Q. 한 번에 몇 초나 늘어나나요?**
없습니다. 안전 엔트리는 메인 부팅 시간에 영향을 주지 않습니다. 타임아웃이 2초인 것만 차이.

**Q. 설치가 실패하면?**
실패해도 A(백업)와 B(안전 엔트리)는 설치 **전**에 만들어지므로 그대로 OS로 들어옵니다.
들어온 뒤 `recovery-menu.sh` → [3] 으로 정리하거나, 상태를 확인하세요.
