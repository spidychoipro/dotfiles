# 1과. 셔뱅, 실행 권한, echo

## 배울 것
- 셸 스크립트가 뭔지, 어떻게 실행하는지
- `echo`로 출력하기

## 이론

**셸 스크립트**는 터미널에서 치는 명령들을 파일에 순서대로 적어둔 것입니다.
파이썬 파일과 다른 점은, 실행할 때 해석기를 직접 지정하지 않고
**파일 첫 줄의 셔뱅이 해석기를 정한다**는 것입니다.

```bash
#!/usr/bin/env bash
```
- `#!` 뒤에 실행할 해석기 경로를 씁니다. 여기선 bash.
- zsh에서도 실행하지만, bash로 돌린다고 지정하는 것. 기초 문법은 같습니다.

**실행하려면 권한이 필요합니다:**
```bash
chmod +x example.sh   # 실행 권한 부여 (1번만)
./example.sh          # 실행
```
- `./`는 "현재 폴더의"라는 뜻. `example.sh`만 치면 PATH에서 찾다가 못 찾을 수 있습니다.

**출력은 `echo`:**
```bash
echo "안녕"          # print("안녕") 과 같음
```
- 따옴표 안의 내용이 그대로 출력됩니다.

## 따라하기 (example.sh)
```bash
#!/usr/bin/env bash
echo "안녕, 셸 스크립트!"
echo "지금 시간: $(date +%H:%M)"
```
`chmod +x example.sh && ./example.sh` 로 실행해보세요.

## 직접 풀어보기 (먼저 풀고, 아래 정답과 비교)
1. `hello.sh` 를 만들고, 자기 이름을 출력하게 해보세요.
   - 실행 방법: `chmod +x hello.sh && ./hello.sh`
2. `echo`를 두 번 써서, 이름과 "공부 시작!"을 각 줄에 출력해보세요.
